2. Hosting e file di log

Questo sito è ospitato presso GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). Può avvenire un trattamento negli USA; vedere l’informativa sulla privacy di GitHub (docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Alla visita vengono trattati dati tecnicamente necessari (indirizzo IP, data e ora, pagina richiesta, tipo di browser) nei file di log del server. La base giuridica è l’art. 6, par. 1, lett. f GDPR (legittimo interesse alla sicurezza e al funzionamento del sito). I log vengono cancellati dopo breve tempo.

3. Cookie, tracciamento e font

Non utilizziamo cookie, servizi di analisi o tracciamento né font o script esterni. Vengono usati solo i font di sistema.

4. Contatto

Se ci contatta via e-mail, telefono o tramite il modulo, trattiamo i suoi dati (nome, e-mail, messaggio) per gestire la richiesta. Il modulo apre il suo programma di posta; il messaggio ci viene trasmesso solo quando lo invia. La base giuridica è l’art. 6, par. 1, lett. b o f GDPR e il suo consenso (lett. a). Conserviamo i dati per il tempo necessario e rispettiamo i termini di legge.

5. Link esterni

Questo sito rimanda a servizi esterni (ad es. XING). Cliccando si applica l’informativa del rispettivo fornitore.

6. I suoi diritti

Ha diritto di accesso, rettifica, cancellazione, limitazione, portabilità e opposizione (artt. 15–21 GDPR) e può revocare il consenso in qualsiasi momento con effetto per il futuro. Ci contatti all’indirizzo sopra indicato.

7. Reclamo

Può presentare reclamo a un’autorità di controllo, ad es. la Garante per la protezione dei dati e la libertà di informazione del Nordreno-Vestfalia, Düsseldorf.
